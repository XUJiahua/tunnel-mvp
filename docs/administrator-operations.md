# 管理员生命周期操作手册

## 增加独立管理员

1. 登录管理员账号，进入“管理员”。确认新账号确实需要全部站点和成员权限。
2. 输入当前管理员密码，再填写新用户名与 12–72 字节初始密码，点击“创建管理员”。请通过已有安全渠道交付初始密码。
3. 新管理员用独立浏览器登录并自助改密。只需应用访问的人员使用“用户组与邀请”，不要创建全局管理员。
4. 现有本地密码成员可在列表“提升为管理员”。停用成员应先启用；OIDC-only 成员不能提升。提升会注销其所有旧设备，必须重新登录。

## 停用、降权与删除

每次重新输入当前密码，操作后清空；密码错误不会保存变更。停用立即退出全部设备，启用后用自己的密码重新登录。降为成员后只保留直接/组应用授权。删除账号同时移除组成员引用，无法用旧密码登录。

系统拒绝停用、删除或降权最后一个启用的本地密码管理员。先创建并实际验证第二位管理员，再停用或删除旧账号。操作自己时，成功后当前控制台会要求登录。UI 确认框之外，服务端也独立执行这些限制。

审计事件前缀为 `administrator_`，记录操作者用户名、目标账号 ID 和 create/promote/demote/disable/enable/delete，不记录当前或初始密码。成员管理入口不能绕过管理员专用操作。

## 恢复与升级

忘记密码使用 [设备、退出与离线恢复](session-operations.md)，先停止 Server 后为已有管理员重设密码；不会自动提升成员。保留单进程数据目录锁与备份流程。本层没有新增数据库格式；回滚程序前仍按 [存储手册](storage-operations.md)备份。

发布构建使用 GoReleaser v2.17.1，先执行 `make release-check` 再 `make release-snapshot`。六个平台的压缩包必须全部通过 archive/CRC/SHA-256 和文档内容检查；失败时保留日志并停止发布，不能仅因 GoReleaser 报 succeeded 就上传或发布。当前修复是固定已验证工具版本，升级工具需重新验证完整快照。
