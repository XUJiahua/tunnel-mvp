# 登录、成员索引与管理目录查询

本批扩展可选 `LoginReader` 和 `DirectoryReader`，保留原 Repository 的 Snapshot/Update/Close 合约。内置 JSON/SQLite 不再为密码登录、OIDC issuer/sub 查找以及站点、应用、成员、组、角色、邀请、组织目录复制完整状态；第三方旧适配器保留快照兼容。实现了查询接口的适配器发生错误时，控制面拒绝请求，不回退快照。

## 事务与成员关系

SQLite 的 `group_members(group_id,user_id,position)` 和 `group_members_user(user_id,group_id)` 是派生索引，组 JSON payload 仍是规范数据。启动时先加载并完整验证规范状态，再在事务中重建索引；旧数据库、跨后端恢复和旧二进制写过的数据库都走同一过程。schema/backup 仍为 v10，索引不写入可移植备份。重建成本与成员关系总数成正比。

Update 的边界仍是一次回调：持有 Store 写锁，复制状态，执行业务回调和全部引用/最后管理员/委派上限校验，再在一个 SQLite 事务中写入变化实体、直接授权及组成员索引。任何一步失败都会回滚，不发布内存状态、差异缓存或新修订号。提交成功后发布全部缓存和状态并递增进程修订号。无变化的组不重写索引行。

成员查询按 user_id 索引连接组表，再验证组 ID、组织和规范 MemberIDs。派生索引的额外行不能凭空授予权限。不能运行中直接修改数据库；缺失关系会拒绝对应授权，只有停机校验/重开才能重建。索引不是另一套授权来源，也未引入跨进程写入能力。

用户名按唯一索引点查；OIDC 精确匹配 issuer/sub，并保留非空 issuer 条件以使用现有部分唯一索引。禁用账号仍可被存储层读取，控制面保留禁用检查、dummy bcrypt、登录限流及访问锁。OIDC 外部状态查询后的第二次本地绑定校验仍在变更锁内执行。

## 有界目录与修订号

可信控制层根据当前用户构造组织、管理员、直接/组授权并集和角色能力过滤，客户端只提供 limit/cursor。SQLite 在 WHERE 中过滤，再按 position 取最多 limit+1 行；用户页的直接授权和角色按本页 ID 批量读取。JSON 在读锁内筛选，仅复制当前投影。存储读锁覆盖全部 SELECT，与 Update/Close 排序，因此用户、授权和角色不会混用不同提交。

游标包含随机进程代际、成功提交修订号、资源种类/操作者/权限过滤的 SHA-256 和最后位置。下一页遇到写入或重启返回冲突，不能接续旧集合；回调、验证或落盘失败不使游标失效。游标可更换页面大小。它没有签名，也不是授权凭据：每页仍从当前用户重新构造全部过滤；更改位置只会跳过已授权记录。无效或跨作用域游标拒绝。

不传 limit 保留旧完整数组 API；前端对目录接口自动请求每页 100 条，全部完成后发布给页面，409 时丢弃已读页并从头重试一次。角色接口仍是 roles/permissions 对象。虚拟默认组织只出现在第一页，额外占一条固定记录。频繁写入时第二次冲突直接失败，避免无限重试。

## 查询边界

本批没有消除所有 O(N) 工作。JSON 仍遍历所选实体；SQLite 组织和复杂权限过滤可能检查多行，返回条数有界不等于扫描成本有界。前端最终仍持有整个可见集合。写入仍全量复制/验证，启动仍加载规范状态并重建成员索引。实时 Agent 清单、状态/监控聚合、审计所有权推导、批量撤销和部分后台状态同步仍使用全状态；没有把动态连接强行纳入配置修订游标。后续可针对这些聚合单独建模。

控制面仍单进程独占目录；修订号是本进程分页一致性标记，没有持久 outbox、共享会话、PostgreSQL 或 HA。下一阶段按 [HA 分解](control-plane-ha.md) 实施。

## 验证与基准

覆盖两后端的目录字段/可见性/分页一致性、调用方副本、跨组织/跨操作者游标、提交/失败/重启、并发多 SELECT 版本、部分读取失败及错误计数。真实 SQL trigger 验证成员索引、用户实体、缓存与游标原子回滚；覆盖索引缺失/额外行、重开和双后端恢复。EXPLAIN 验证用户名、OIDC 和成员关系使用索引。控制面验证失败不回退及 HTTP 状态，前端单元测试验证丢弃部分页、一次重试和写请求只发送一次；浏览器使用 103 站点并在页间真实创建第 104 个站点制造冲突。
