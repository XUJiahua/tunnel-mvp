# 同站点 Agent 实例

## 标识与信任边界

一个站点可登记最多 16 个实例。每个实例使用独立的随机 ID 和 48 字节十六进制令牌；持久化只保存 SHA-256。握手绑定 siteID + instanceID + token，实例 ID 在所有站点间唯一。相同实例只能同时建立一条隧道，重复返回 409；不同实例可同时在线。旧客户端不发送 instanceID，仍使用站点令牌和原有单连接约束。

`sites:manage` 能力只在所属组织内管理登记、禁用、轮换和删除。清单不含哈希或令牌；明文仅登记/轮换响应一次。实例名称、来源 IP、连接时间、活动 TCP 通道数和自报版本可供运维诊断。IP 使用 TCP 对端，不信任 X-Forwarded-For；版本由 Agent 自报，不是二进制完整性证明。

## 路由和故障语义

新建 TCP 通道在当前在线且未关闭的实例间轮询；仅在 TCP 通道尚未交付给 HTTP 层时尝试下一个实例。按应用的 HTTP 连接池保持复用，因此轮询单位是新 TCP 通道，不是请求。上传、WebSocket、SSE 和复用连接固定属于承载实例。

单实例停机、禁用、轮换和删除关闭该实例隧道和通道，清除站点的空闲连接池。其他实例正在使用的连接继续运行。新连接使用剩余在线实例。已经发送的 HTTP 请求不重放，上传不会重新提交；WebSocket/SSE 客户端应自己重连。在线表示隧道存在，不保证该实例的上游网络健康；每个实例必须配置等价的网络可达范围，本地 ACL 继续逐目标强制执行。

站点 `legacyDisabled` 可独立关闭兼容令牌入口，不影响登记实例。站点令牌轮换视为全站点凭据事件：断开所有实例、替换所有实例凭据为未公开随机值，并禁用/标记为必须轮换。必须逐实例轮换后才可重新启用，不能以普通“启用”恢复旧凭据。

## 存储与并发

授权状态 schema/backup v7，SQLite v6 → v7 在单事务中添加 legacy_disabled 与 agents 表，导入、备份和引用校验覆盖实例。旧 JSON 的空字段省略以保留旧备份校验。删除站点清理实例登记。恢复旧备份会恢复当时凭据，与原站点令牌恢复语义一致，故事件恢复后需复查与轮换。

管理员写请求沿用访问写锁重新鉴权；连接表通过独立互斥锁和原子 closing 标记阻止撤销后新选择。实例计数不保存令牌。诊断报告的实例标识由认证后的握手头覆盖，不能由报告 JSON 冒充。

这是单控制面上的 Agent 冗余。控制面重启仍会断开全部隧道，本功能不提供控制面 HA。

## 验收

两套授权存储执行真实 Agent 集成，包含同时连接、凭据互换拒绝、重复实例、单实例关闭通道、健康实例继续代理、站点全局轮换与逐实例恢复。浏览器使用两个独立 Agent 进程，登记 UI、1 MiB 上传、HTTP/WS/SSE、进程故障、单实例撤销和重连；旧 Keycloak/OTP 等回归继续全量执行。SQLite 旧布局升级和 JSON/SQLite 交叉备份单独校验。
