# Agent 接入交互原型

原型入口：`/prototypes/agent-onboarding.html?variant=B&start=1`。
单文件源码：[agent-onboarding.html](../web/public/prototypes/agent-onboarding.html)。
它沿用控制台的配色与站点布局，用合成数据演示接入流程，不调用业务 API。

## 体验任务

1. 直接填写内网应用地址、选择部署方式，确认本地授权；无需提前给站点、设备或应用起名。
2. 下载目标生成的配置，复制启动命令，点击“我已启动，检查连接”。
3. 连接后自动识别主机名，验证应用连接并完成，打开示例应用或返回站点。
4. 任一步关闭窗口，从站点“继续接入”；输入、步骤与页面内进度保留。
5. 完成后按需点击“修改名称”，修改设备显示名称；应用名、站点名放在可选设置中。
   支持取消、保存、清空回退到默认名称，以及恢复使用主机名。

页面顶部的原型工具独立于产品界面。关闭接入窗口后，可以切换现状对照、失败场景、长名称与大字。
切换不清空输入；“重置”或刷新页面才清空当前内存状态。

- 新版：`?variant=B`，现状对照：`?variant=A`。
- 正常接入：`?variant=B&scenario=success&start=1`。
- 白名单拒绝：`?variant=B&scenario=acl&start=1`，体验修正配置、重启说明和重新检测。
- 凭据失效：`?variant=B&scenario=credential&start=1`，体验只重新生成当前实例的凭据。
- 不填写首个应用时，可以单独完成 Agent 接入；已有目标也可以暂缓验证。

## 交互决策

- 首次接入从应用地址开始，不出现站点名称或 Agent 名称输入。站点、独立实例所需记录由系统准备。
- 设备连接成功后上报主机名作为默认显示名。站点也使用自动默认名称，应用默认使用目标地址。
- 命名是连接后的可选整理操作。修改显示名不修改机器主机名，不改变记录 ID、凭据或连接状态。
- 设备始终使用独立凭据，不默认使用兼容站点令牌。
- Agent 在线与应用验证分别呈现。应用未验证时，站点保留“继续验证”入口。
- IP 目标生成精确地址及端口规则；内网域名要求用户明确填写允许网段，并保留精确 host 限制。
- 凭据不写入下载的 JSON 或进程参数；部署说明可以重复查看，凭据恢复单独处理。
- Linux 先验证连接，也可查看常驻服务路径；Docker 和手动平台具有各自的命令展示。
- 窄屏收起冗长导航，弹层正文单独滚动，底部操作固定且不遮挡最后内容。

## 模拟边界

连接、探测、凭据重置、应用页面和后台数据全部模拟。原型不提供可执行 Agent 下载，
“下载 Agent”实际下载边界说明；配置、Compose 与 systemd 文件仅用于检查下载交互。
所有 ID、令牌、域名、主机名和镜像均为占位值，不可用于真实部署；文件不包含现有 preview 的秘密。
主机名在模拟连接完成时由预置设备数据提供，不从浏览器或控制面机器读取。
原型未实现凭据持久化、安装器、服务托管、后端注册事务、重试幂等、访问权限或服务端校验。
当前本地进度只保存在页面内存，不承诺刷新或跨设备恢复。

它不改变现有控制台流程、数据库或 Agent 协议，不代表真实业务实现已完成。

## 本地运行

从仓库根目录执行：

```sh
python3 -m http.server 38417 --bind 127.0.0.1 --directory web/public/prototypes
```

打开 `http://127.0.0.1:38417/agent-onboarding.html?variant=B&start=1`。
该目录仅包含原型；不要将整个仓库作为公开静态目录。

公开预览随完整 Next.js 静态导出、embed 和 Go 构建交付；使用项目 preview 管理器刷新并检查 status。

## 验证范围

已通过 Chromium 实际点击、键盘、复制和下载检查：正常接入、关闭恢复、异步检查期间退出、
现状/新版切换、白名单拒绝与重试、单实例凭据恢复、无首个应用、域名网段确认及部署方式切换。
新一轮验证另外覆盖不命名直接接入、连接后读取主机名、显示名称的保存/取消/恢复及记录身份不变。
桌面 1440px，以及 390px / 320px 长名称、大字、触摸和滚轮场景均检查完整任务链、
横向溢出、底部操作与最后内容可达。浏览器仿真不代表移动真机验收。

用户验收关注：不用手写 JSON 能否走通、关闭后能否继续、失败后是否清楚在哪台机器修改什么、
以及是否能区分 Agent 已连接和应用已验证。
