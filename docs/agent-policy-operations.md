# 远程策略操作

先按 [Agent 操作手册](agent-operations.md) 登记独立实例。为该 Agent 的本地配置增加 `"remotePolicy": true`，并保留明确的 `allow` 上限。例如本地仅放行 10.10.0.0/16 的 3000 端口，远程即使写 0.0.0.0/0 也不能访问其他网段/端口。

在“Agent 实例”点击“编辑收紧策略”，填写 JSON 数组：

```json
[{"cidr":"10.10.20.0/24","host":"grafana.internal","ports":[3000]}]
```

`host` 可省略；填入时精确匹配大小写无关的目标主机名，同时还需匹配 CIDR/端口。空数组 `[]` 拒绝所有目标。首次启用而未配置策略时也是空策略；先保存规则，再启动已开启开关的 Agent，可避免预期内的初始拒绝。

保存后等待在线清单应用版本与期望一致。Agent 每 5 秒轮询，变化会关闭旧连接；上传由业务方判断是否重试，WS/SSE 客户端自行重连。普通“本地模式”实例不会应用控制面策略，必须在所在主机显式开启。清单的版本是 Agent 自报值，不能作为主机安全证明。

暂时无法读取策略时使用最后有效内容；超过 30 秒未成功获取即关闭隧道，检测额外最多约 8 秒。检查 HTTPS 证书、控制面路由、代理设置、实例凭据和 `/tunnel/policy` 的 401/403/5xx。接口恢复后自动重连。不要为恢复可用性放宽本地 allow 或无限延长策略有效期。

错误 JSON、CIDR、端口或超过规则上限的写入会失败，原策略保留。回滚时在编辑器写回之前审阅过的规则，等待重新应用；不要直接恢复整个授权数据库来回滚单个策略。紧急撤销优先使用“禁用”实例/站点凭据轮换，即时断开而无需等待轮询。

API：GET/PUT `/api/sites/{siteID}/agents/{instanceID}/policy`。PUT 请求体为 `{"allow":[...]}`，不可直接设置版本。仅所属组织 sites:manage 可读写；策略变更进入审计。策略包含在状态备份 v8 中，旧版本二进制不能打开新 SQLite schema。
